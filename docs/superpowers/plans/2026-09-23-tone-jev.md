# tone JEV Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the public inverse of Mind Your Tone at `tone-jev.tomv.uk`, where a bounded language-model feedback loop rewrites text toward one Jev-measured tone target.

**Architecture:** A React client submits optional source text, a known dimension, and a percentage to one Python Worker endpoint. Pure Python orchestration alternates an inexpensive Workers AI writer with `typesafe/jev`, retains the closest of at most four scored attempts, and returns an inspectable result. Native rate-limit bindings bound public use.

**Tech Stack:** Python Cloudflare Workers, Workers AI, TypeSafe Jev, React 18, TypeScript, Vite, Vitest, unittest, Ruff

**Spec:** `docs/superpowers/specs/2026-09-23-tone-jev-design.md`

## Global Constraints

- Visible product title is exactly `tone JEV`; strapline is `tone your mind`.
- Source and every generated phrase are at most 240 characters.
- Exactly one known dimension and a 0–100 target divisible by 5 are accepted.
- Jev is the sole scoring authority and uses a five-anchor Score question.
- At most four attempts are scored; stop within 5 percentage points and return the closest attempt.
- The writer model is `@cf/ibm-granite/granite-4.0-h-micro` with at most 96 output tokens.
- No phrase persistence, generated-text logs, accounts, database, or plaintext secrets.
- Six requests per browser session and thirty aggregate requests per minute per Cloudflare location.

## Review Focus

- Empty source text must generate a usable first candidate rather than fail validation.
- A writer response with commentary or more than 240 characters must be normalized or rejected safely.
- A valid first/source attempt must remain the winner when later rewrites score worse.
- Writer or Jev failure must not leak a partial candidate or trigger unbounded retries.
- Double submission and 429 responses must leave the controls recoverable.
